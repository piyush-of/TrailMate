# Rewards

Principle: **reward real-world activity, not app opens.**

## XP events
| Action | XP | Daily cap |
|---|---:|---|
| Start adventure | +10 | 1/day |
| Every 500 m | +10 | 20 steps |
| Quest challenge done | +20 | – |
| Plant ID | +15 | – |
| Bird ID / call | +20 | – |
| New discovery (first time) | +15 | – |
| Quest complete | +50 | – |
| 30 min outside | +30 | 1/day |
| 60 min outside | +75 | 1/day |
| 7-day streak | +150 | – |

Global safety cap: 500 XP/day. Drop events with impossible speed/time data.

## Anti-cheat (be honest in the post)
Client-side data can be spoofed. We apply plausibility checks and caps (speed, daily limits, timestamps). If a server is added, it re-validates events and applies the same caps. We call it "sanity-checked", not "tamper-proof".
