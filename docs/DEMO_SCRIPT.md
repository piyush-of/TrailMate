# Demo Script (~60 s)

**Setup before recording:** app installed as PWA, offline pack downloaded, phone on a campus path, screen recording on. Practise twice.

| Time | Show | Say |
|---|---|---|
| 0–8 s | Quick setup: 30 min · Relax · Easy → quest appears | "I built TrailMate because AI shouldn't always keep us staring at screens." |
| 8–16 s | Toggle **Airplane Mode ON** (show status bar) | "No signal. No cloud. Everything runs on this phone." |
| 16–32 s | Walk, point camera at a tree/plant → "Analyzing locally…" → result + confidence | "An open-weight vision model identifies what I'm looking at — on-device." |
| 32–42 s | Quest ticks off, XP toast, badge: **No Signal Explorer** | "Real-world actions earn XP, not screen time." |
| 42–54 s | Recap: distance, time, discoveries, Touch Grass Score, journal line | "A tiny adventure diary, generated offline." |
| 54–60 s | Face/outdoor shot | "The AI ran locally, my data stayed on my device, and the shortest path to it was a walk outside." |

## Tips
- Show the phone outdoors for most of the video; keep screen time short.
- If ID is wrong during a take, show the "Not sure" state — honesty is a feature.
- Record a backup take with a known-good object.
